## What Worked

- **The config-home subtlety (F-6) was caught by building the exact real-world scenario, not a
  simplified stand-in.** A fixture that actually splits the store (`[store]` redirect + a decoy
  `[legacy]` in the locator + the real one in the store's own `config.toml`) is what proved
  `configured_directory`'s existing fallback logic was *already correct* — the defect was entirely
  in *where the operator's data lived*, not in the resolver. A simpler fixture (flat store,
  `[legacy]` in the one config file) would have passed either way and never distinguished the two.
- **The plan-set escape hatch (D-2) had a real, undiscovered edge case the fixture-writing process
  itself surfaced**: a naive "additional dir with its own `project-plan.md`" fixture failed not
  because of a bug in this slice's code, but because it exposed a pre-existing architectural
  property (`PROJECT_NUMBER` is a store-wide constant) the slice-doc's own wording ("its own plan
  set") didn't anticipate. Caught by actually running the fixture rather than asserting the
  intended behavior abstractly, and resolved by testing the realistic case (a detached arc) instead
  of forcing the unrealistic one to pass.
- **Two genuine `Store::open` usage bugs were caught in the *test*, not the implementation**, by the
  same discipline: when a fixture's assertion failed, tracing *why* (rather than adjusting the
  assertion to match) found that `Store::open` takes a store root directly with no internal
  `StoreHome` redirection — a distinction every other test in this suite had never surfaced, since
  none before this slice used a genuine split-store layout.
- **`toml_edit`'s auto-vivification default (an inline table) was checked empirically before
  relying on it** — a two-line standalone sanity script, run *before* wiring the real write-back,
  caught that a bare `doc["legacy"][...]` assignment produces `legacy = { additional_paths = […] }`
  rather than a `[legacy]` section header, inconsistent with every other section in this file. Cheap
  to catch early; would have been a confusing, hard-to-diagnose formatting inconsistency in the
  live config otherwise.
